# Архитектура

Монолит на Nuxt: клиент и API в одном репозитории. Данные — PostgreSQL через Prisma. Медиа — объектное хранилище.

## Слои

- **app/** — интерфейс: страницы, компоненты, клиентский стейт
- **server/** — HTTP API (Nitro), доступ к БД
- **prisma/** — схема данных и миграции
- **public/** — статика (обложки, ассеты без сборки)

## Клиент (`app/`)

- **pages/** — маршруты и экраны
- **layouts/** — оболочки страниц (guest, auth, app)
- **components/** — UI и блоки интерфейса
- **composables/** — переиспользуемая логика экранов и карточек
- **stores/** — Pinia-стор
- **types/** — типы ответов API для клиента
- **assets/** — стили и ресурсы сборки
- **plugins/** — плагины Nuxt

### Компоненты (`app/components/`)

- **ui/** — примитивы (кнопки, поля)
- **cards/** — карточки сущностей (альбом, трек, артист)
- **lists/** — полки и списки
- **menus/** — меню (floating / sheet)
- **modals/** — модальные окна
- **player/** — плеер
- **navbar/**, **headers/** — навигация и шапки

## Сервер

- **server/api/** — эндпоинты REST (описание: `docs/api.md`)
- **server/utils/** — Prisma-клиент и вспомогательные модули

## Данные

- **prisma/schema.prisma** — модели
- **prisma/migrations/** — история схемы БД
- **docker-compose.yml** — локальный PostgreSQL
