# Проверка цветов интерфейса Pulsar

## Направление

Спокойный нейтральный интерфейс с хорошо различимыми уровнями поверхности, без ярких декоративных акцентов. Существующая композиция и обложки сохраняются. Тёмная тема — основная; светлая — полноценная альтернатива, доступная на экранах до и после входа.

| Роль | Тёмная | Светлая |
| --- | --- | --- |
| Внешний фон | `#0b0d10` | `#e9edf2` |
| Фон содержимого | `#12151a` | `#f8f9fb` |
| Поверхность | `#222831` | `#ffffff` |
| Поверхность при наведении | `#303844` | `#e4e9ef` |
| Основной текст / основной CTA | `#f5f7fa` | `#18212d` |
| Вторичный текст | `#b2bdca` | `#536174` |
| Ошибка | `#ff7b83` | `#ba2536` |

Текст на основном CTA использует цвет фона содержимого. Границы и фокус должны различаться на соседних поверхностях; для вторичного текста ориентир — контраст не ниже 4.5:1. Для текста на динамических обложках нужна отдельная защищённая контрастом поверхность или затемнение: нельзя полагаться на произвольный цвет картинки. Иконки, прогресс и интерактивные состояния должны оставаться различимыми.

## Реализация (код)

- `tone-*` и legacy `primary-*` приведены к ролям палитры: `primary-gray` → вторичный текст (не тёмная заливка); `primary-gray-dark` → поверхность; `primary-black` → canvas; `primary-white` → основной текст/CTA.
- Затемнения на обложках и backdrop модалок — фиксированный `black/α`, не theme-токены.
- Hero/sticky на `coverColor` — класс `media-hero` (текстовые токены тёмной темы на акцентном фоне).
- Тема: cookie `pulsar-theme` (`light` | `dark` | `system`), blocking-скрипт в `head`, `useTheme` + `ThemeToggle` (guest / auth / settings). Без новых пакетов.
