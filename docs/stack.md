# Стек

Стер приложения по приоритету

## Клиент

- **Nuxt 4** — фреймворк приложения
- **Vue 3** — UI-слой
- **Vue Router** — маршрутизация
- **Pinia** — состояние клиента
- **Tailwind CSS 4** — стили
- **VueUse** — утилитарные composables
- **Floating UI** — всплывающие меню
- **Swiper** — карусели
- **Phosphor Icons** — иконки
- **Onest** — шрифт (кириллица и латиница)

## Сервер

- **PostgreSQL** — реляционная СУБД
- **Prisma** — доступ к данным и миграции
- **Nitro** — HTTP API в составе Nuxt
- **nuxt-auth-utils** — сессии (sealed cookie) и хеш паролей
- **S3-совместимое хранилище (MinIO / S3)** — медиафайлы
- **sharp** — обложки в WebP 800×800
- **music-metadata** — длительность трека из файла

## Инфраструктура разработки

- **Docker Compose** — PostgreSQL и MinIO в локальном окружении
  - MinIO API: `http://127.0.0.1:9000`, консоль: `http://127.0.0.1:9001`
  - бакет `media` создаётся контейнером `minio-init`
