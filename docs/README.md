## Проверки

Используй Node.js 24 и `npm ci` для установки зависимостей. `npm run verify` запускает линтер, проверку типов Nuxt и автоматические тесты; `npm run build` проверяет production-сборку. Те же команды выполняются в CI для pull request и изменений в `main`. Текущие тесты покрывают общие функции пагинации и сортировки API; они не заменяют интеграционные проверки с базой данных и хранилищем.
