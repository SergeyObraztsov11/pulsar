# Правила агента

Отвечай пользователю на русском языке. Перед работой прочитай правила, относящиеся к задаче:

- [Качество кода и проверки](.agent/rules/code-quality.md) — при изменении кода.
- [Документация](.agent/rules/documentation.md) — при изменении документации.
- [Git](.agent/rules/git.md) — при работе с Git.
- [Работа с Cursor](.agent/rules/cursor.md) — при передаче задачи Cursor и приёмке результата.

Индекс документации: [docs/README.md](docs/README.md). Локальные правила Cursor могут содержать дополнительные сведения об интерфейсе; при противоречии рабочие правила из `.agent/` имеют приоритет.
